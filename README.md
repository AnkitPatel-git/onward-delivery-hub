# SaiTrackSolutions — PAN India Courier & Cargo Services

## Project Overview

**SaiTrackSolutions** is a professional logistics platform offering PAN India courier & cargo services. Built with speed and efficiency in mind, it provides a one-stop-shop for all logistics needs, including air cargo, surface transport, rail freight, warehousing, and last-mile delivery.

---

## Features

- **Real-Time Tracking**: Innovative tracking system for shipments (Demo ID: `ODH12345678`).
- **Full Coverage**: Serviceable across all major Indian cities with a robust hub network.
- **Service Diversity**: Specialized solutions for various industries including Automobiles, Steel, and Wind Power.
- **Client Management**: Secure portal for partners and clients.

## Technologies Used

- **Framework**: React.js with TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **UI Components**: shadcn/ui (Radix UI)
- **Icons**: Lucide React
- **Animations**: Framer Motion / CSS Transitions
- **Build Tool**: Vite

## Getting Started

### Prerequisites

- Node.js (v18 or later recommended)
- npm or bun

### Installation

1. **Clone the repository**:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. **Install dependencies**:
   ```sh
   npm install
   ```

3. **Start the development server**:
   ```sh
   npm run dev
   ```

## Development

- **Build for production**:
  ```sh
  npm run build
  ```

- **Preview production build**:
  ```sh
  npm run preview
  ```
